# Brise

A desktop shell for Niri built with Quickshell, featuring full-width and minimal bars, Spotify controls, per-app audio, Bluetooth, wallpapers, clipboard history, and a system tray.

## Requirements

- Quickshell with the Niri, PipeWire, MPRIS, Bluetooth, SystemTray, and BackgroundEffect modules. The installed package must be compatible with your system's Qt version.
- Python 3, dbus-python, and PyGObject.
- PipeWire/WirePlumber (`wpctl`), PulseAudio-compatible tools (`pactl`, usually provided by `libpulse`), BlueZ, and wl-clipboard (`wl-copy`, `wl-paste`).
- Noto Sans for afeto. Tamzen8x16b is bundled with genesis in `themes/genesis/fonts/`, along with its license, and loads directly from the theme. Tabler icons and their license are in `fonts/`.
- Background blur in afeto requires compositor support.

## Installation

Place the project in `~/.config/quickshell/brise`, or keep your checkout in another directory. From the project directory, run:

```bash
chmod +x brise install-command.sh
./install-command.sh
```

This installs a launcher at `~/.local/bin/brise` pointing to the project. Add `~/.local/bin` to your PATH if needed. If you move the project, update the launcher. The installer does not start services or change your Niri configuration.

```bash
~/.local/bin/brise start
~/.local/bin/brise stop
~/.local/bin/brise restart
```

## Restart Brise

To restart the shell in the background while keeping your selected theme and preferences:

```bash
brise restart
```

If `brise` is not in your PATH, use `~/.local/bin/brise restart`. Theme changes normally reload automatically; use this command when a full restart is needed.

## Themes

```bash
brise theme list       # List installed themes
brise theme            # Show the active theme
brise theme afeto
brise theme genesis
```

Your selection is saved and reloads automatically while the shell is running. `afeto` is the default when no local selection exists.

- **afeto:** translucent backgrounds with blur, Noto Sans, and rounded corners.
- **genesis:** opaque black backgrounds, bold Tamzen, #DED6C5 text, four cut corners on panels, and pointed ends on the minimal bar and system tray.

Each theme has its own palette in `themes/<name>/Palette.qml`. To create another theme, copy a theme directory, choose a name containing letters, numbers, hyphens, or underscores, and select it with `brise theme <name>`. Keep the palette properties to maintain compatibility with the components.

`Theme.qml` is generated by the theme command and ignored by Git. Personal preferences are stored in `preferences.ini`, which is also ignored. History and the selected wallpaper are stored in `${XDG_STATE_HOME:-~/.local/state}/brise`.

## Start with Niri

Add this at the top level of `~/.config/niri/config.kdl`, outside `binds`:

```kdl
spawn-sh-at-startup "~/.local/bin/brise start"
```

If you use another shell or bar, remove its startup command to avoid running two bars. Brise does not require a separate clipboard daemon.

Example shortcuts inside the `binds` block:

```kdl
Mod+V { spawn-sh "~/.local/bin/brise clipboard"; }
Mod+W { spawn-sh "~/.local/bin/brise wallpapers"; }
Mod+P { spawn-sh "~/.local/bin/brise power"; }
```

Replace existing shortcuts using the same keys rather than adding duplicates. The `dashboard`, `audio`, `bluetooth`, `tray`, `tray-settings`, and `close` commands are also available.

## Controls

- **Clock:** left-click to open the calendar and Spotify panel; right-click to switch between full-width and minimal bars. Your preference is saved.
- **Music:** Spotify only. The minimal bar shows the track and artist with scrolling text. The full-width bar shows circular album art that spins during playback and stops when paused.
- **System tray:** right-click the bar anywhere except the clock to show application icons. Left-click an icon to activate the application; right-click to open its menu. The settings button lets you choose which currently registered applications appear in the full-width bar.
- **Audio:** input and output cards, device selection, and per-app volume and mute controls. A themed on-screen indicator appears when the system default microphone or output is muted or unmuted, including changes made by external shortcuts. The input prefers the Starship/Matisse analog device when available; you can select and save another input.
- **Bluetooth:** scan for up to 20 seconds, connect, disconnect, unpair paired devices, and pair using a PIN or confirmation. Keep the panel open while pairing.
- **Wallpapers:** centered panel with thumbnails and automatic refresh. By default, searches `~/Imagens` and conventional wallpaper directories. Change the directory in the palette. The selected image is applied to all monitors.
- **Clipboard:** text and images copied while Brise is running, with search and keyboard navigation. Use the arrow keys and Enter, or click an item, to copy it. Paste normally with Ctrl+V. Stores up to 15 items, with a 10 MiB limit per item. Does not import history from other shells.
- **Power:** restart, shut down, or suspend. Click an icon once to execute the action.
- **Panels:** press Esc or click outside to close.

## Development

`brise preview` opens a composition and saves a screenshot without triggering system actions. QML components are in the project root; integrations are in `DesktopState.qml` and Python helpers. Brise uses native menus for system tray applications; the root QML file already enables QApplication.

Brise does not include an application launcher, desktop notifications, or a lock screen. The system tray is separate from desktop notifications.
